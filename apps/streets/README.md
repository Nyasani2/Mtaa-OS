# STREETS OS APP

Urban intelligence + street-level mobility layer of MTAA OS.

## Core Purpose
- Live city activity map
- street commerce signals
- crowd + movement detection
- informal transport + foot traffic intelligence
- event + hotspot detection
- local economic activity layer

## Architecture
- streets/intelligence (AI brain)
- streets/maps (visual layer)
- streets/feed (activity stream)
- streets/dispatch-lite (optional micro-mobility layer)
