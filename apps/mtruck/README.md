# MTRUCK OS

Freight + logistics intelligence system for MTAA OS.

## Core Purpose
- Cargo dispatch (heavy + light freight)
- Fleet matching (trucks, pickups, vans)
- Warehouse + pickup coordination
- Route optimization
- Load batching system
- Freight pricing engine

## Architecture
- mtruck/dispatch
- mtruck/pricing
- mtruck/fleet
- mtruck/tracking
- mtruck/intelligence
